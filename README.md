# ॥ धर्माकूतोदाहृत-प्रमाण-सूची (युद्धकाण्डम् — सम्पूर्णम्) ॥
### Dharmakūtam Citations Map — PPSM (PurnaPrajna Samshodhana Mandiram)

An interactive citation and pramāṇa index for **Dharmakūtam (Yuddhakāṇḍam)**, mapping verified textual citations directly to corresponding page references in the digitized volume (`Dharmakutam_ppsm.pdf`).

## Features
- **Interactive Search & Filter**: Easily search across citations, source texts, authors, and kāṇḍa contexts.
- **Deep-linking to Source PDF**: Direct links navigating to specific pages of `Dharmakutam_ppsm.pdf`.
- **Complete Yuddhakāṇḍa Coverage**: Full comprehensive citation listing prepared by PPSM.

## Files
- `index.html`: Web interface for searching and browsing citations.
- `Dharmakutam_ppsm.pdf`: Complete digitized edition of Dharmakūtam Yuddhakāṇḍam.
